# Support

For installation and expected workflow questions, start with the
[Quickstart](docs/QUICKSTART.md) and [Testing guide](docs/TESTING.md).

Project support covers exporter behavior, workbook readiness, release assets,
and the optional local XLSX sanitizer. It does not provide Google Ads strategy,
validate conclusions produced by a person or LLM, decide whether data may be
shared, or evaluate a third party's privacy, retention, or security practices.

For a reproducible non-sensitive bug, use the bug-report form at
https://github.com/wvuhskr/google-ads-analysis-workbook/issues/new/choose and include
the smallest safe description. Do not upload advertiser data, workbook files,
customer IDs, Google Sheet URLs, campaign/search-term data, or performance
values. Privacy and security concerns belong in private vulnerability reporting
at https://github.com/wvuhskr/google-ads-analysis-workbook/security/advisories/new as
described in [SECURITY.md](SECURITY.md).
